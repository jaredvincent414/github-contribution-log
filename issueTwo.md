## Problem Summary

Web Scrobbler currently does not provide a full way to export and reimport extension settings. This makes it difficult for users who have customized their setup to move those settings between browsers or computers. The requested feature is a human-readable JSON backup system that can export settings and later restore them.

## Why I Chose This Issue

I chose this issue because I love music and Web Scrobbler is directly connected to how people track and organize their listening history. I also recently worked on a Chrome extension, so this issue feels like a good opportunity to build on that experience while learning more about a real-world browser extension codebase. Since the feature involves extension settings, storage, and user workflow, it is a practical next step for me to contribute meaningfully while strengthening skills I have already started developing.
